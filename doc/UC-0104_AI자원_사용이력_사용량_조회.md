# UC-0104. AI 자원 사용 이력 및 사용량을 조회한다

## 1. Use Case 개요

| 항목 | 내용 |
|---|---|
| Use Case ID | UC-0104 |
| Use Case 명 | AI 자원 사용 이력 및 사용량을 조회한다 |
| 주요 Actor | 개발자 / 관리자 |
| 주요 시스템 | 개발시스템 / AI Gateway |
| 목적 | 멀티테넌트 환경에서 표준API 및 MCP 사용 이력과 사용량을 조회한다 |
| Trigger | 개발자 또는 관리자가 AI 자원 사용 현황을 확인하고자 하는 경우 |
| 관련 SFR | SFR-010 |

## 2. 사전 조건

- AI Gateway가 API/MCP 호출 이력을 수집하고 있어야 한다.
- 사용자에게 해당 정보시스템의 사용 이력 조회 권한이 있어야 한다.
- Tenant, Agent, Model, MCP 등의 호출 식별 정보가 기록되어 있어야 한다.

## 3. 기본 시나리오

| 단계 | Actor | 수행 내용 |
|---|---|---|
| 1 | 개발자/관리자 | 개발시스템에서 AI Gateway 관리 화면에 접속한다. |
| 2 | 개발시스템 | 조회 권한이 있는 정보시스템 별 인증 키 목록을 보여준다. |
| 3 | 사용자 | 조회 기간 및 AI 자원 조건을 설정하고 검색한다. |
| 4 | 개발시스템 | 해당 조건에 따른 API/MCP 호출 이력을 인증 키 별 조회한다. |
| 5 | 사용자 | 목록에서 상세 호출 이력을 선택하여 확인한다. |
| 6 | 개발시스템 | 조회 조건의 Tenant/Agent/Model/MCP별 사용량 집계를 제공한다. |
| 7 | 개발시스템 | 조회 조건의 호출 건수, Token, 응답시간, 성공/실패 등의 정보를 제공한다. |
| 8 | 사용자 | 인증 키 목록에서 선택하여 상세 사용 이력을 다운로드 요청한다. |
| 9 | 개발시스템 | 선택한 인증 키와 검색조건에 해당하는 로그를 파일로 만들어 제공한다. |

## 4. 예외/대안 시나리오

- 조회 권한이 없는 Tenant 조회 요청 → 접근 차단
- 존재하지 않는 Tenant/Agent 조회 → 조회 결과 없음
- 보존기간이 지난 이력 조회 → 정책에 따른 조회 제한

## 5. 사후 조건

- 개발자는 자신에게 권한이 부여된 Tenant의 AI Gateway 사용 현황을 확인할 수 있다.
- **(UC-0303 확정사항)** 관리자는 테넌트 구분 없이 전체 Tenant의 AI Gateway 사용 현황을 통합 조회할 수 있다.
- AI Model 및 MCP별 사용량과 호출 이력을 기반으로 사용량을 확인할 수 있다.

### 조회 항목 정의

| 구분 | 주요 정보 |
|---|---|
| Tenant | Tenant ID, Tenant Name |
| Agent | Agent ID, Agent Name |
| API | API 종류, Endpoint |
| Resources | Model Alias, 실제 Model/Provider, MCP Server, Tool |
| 호출 | 호출시간, Trace ID, 요청/응답 상태 |
| 사용량 | Input Token, Output Token, Total Token |
| 성능 | 응답시간, 오류율 |

## 6. 미결/후속 검토 사항

- **Actor 용어 혼용**: 개요에는 "개발자/관리자"로 명시되어 있으나 기본 시나리오 3단계부터 "사용자"로 표기가 바뀜. 개발자·관리자를 포괄하는 의도인지, 별도 Actor(예: 조회 전용 권한자)가 있는지 확정 필요.
- **로그 실시간성 미정의**: 호출 발생 시점과 조회 가능 시점 사이의 지연(실시간/준실시간/배치)이 정의되어 있지 않음. UC-0401(사용 로그 저장) 상세화 시 함께 정의 필요.
- **보존기간(retention) 정책 미정의**: 예외 시나리오에 "보존기간이 지난 이력은 정책에 따라 제한"이라고만 되어 있고, 구체적 보존기간(개월/년) 수치가 없음.
- **다운로드 파일 형식 미정의**: 9단계 "로그를 파일로 만들어 제공"에서 파일 형식(CSV/Excel 등) 및 대용량 건수일 경우의 처리 방식(동기/비동기 생성) 미정의.
