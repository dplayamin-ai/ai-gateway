# UC-0401. 사용 로그를 저장한다

> ⚠️ 본 문서는 원본 PPTX(Slide 2)의 Use Case 목록에는 존재하나 상세 시나리오가 작성되지 않았던 항목입니다. UC-0102, UC-0103의 기본 시나리오 마지막 단계에 반복적으로 등장하는 "호출 정보 및 사용량 이력을 기록한다"가 바로 이 UC에 해당하며, UC-0104(사용 이력 조회)의 전제가 되는 UC이기도 합니다. 아래는 그 연결관계를 반영한 초안이며, 저장 방식의 세부 사항은 별도 확정이 필요합니다.

## 1. Use Case 개요

| 항목 | 내용 |
|---|---|
| Use Case ID | UC-0401 |
| Use Case 명 | 사용 로그를 저장한다 |
| 주요 Actor | AI Gateway (시스템) |
| 주요 시스템 | AI Gateway |
| 목적 | AI Gateway는 표준 API, 표준 MCP 사용에 대해 로그를 남긴다 |
| Trigger | UC-0102(표준API 호출) 또는 UC-0103(MCP 호출) 처리가 완료(성공/실패 포함)된 경우 |
| 관련 SFR | SFR-010, SFR-005, SFR-009 |

## 2. 사전 조건 (초안)

- AI Gateway를 통해 표준API 또는 표준MCP 호출이 발생해야 한다.
- 호출 시 인증키를 통해 Tenant, Agent, 사용 자원(Model/MCP)이 식별 가능해야 한다.

## 3. 기본 시나리오 (초안 — 세부 단계 미확정)

| 단계 | Actor | 수행 내용 |
|---|---|---|
| 1 | AI Gateway | 표준API(UC-0102) 또는 표준MCP(UC-0103) 호출이 완료(성공/실패)된 시점에 로그 기록을 시작한다. |
| 2 | AI Gateway | 호출 식별 정보(Tenant, Agent, 인증키, 사용 자원, 호출시간, Trace ID 등)를 수집한다. |
| 3 | AI Gateway | 사용량 정보(Input/Output/Total Token 등, MCP의 경우 해당 사용량 지표)를 수집한다. |
| 4 | AI Gateway | 성능 정보(응답시간, 성공/실패 여부, 오류코드 등)를 수집한다. |
| 5 | AI Gateway | 수집된 정보를 로그 저장소에 저장한다. |

## 4. 예외/대안 시나리오 (미정의)

- 로그 저장 자체가 실패하는 경우 → **(미결)** 재시도 여부, 저장 실패가 API 응답 자체에 영향을 주는지(즉 로그 실패 시 API 요청도 실패 처리할지, 로그와 무관하게 API 응답은 정상 반환할지) 확정 필요.
- (그 외 미정의)

## 5. 사후 조건

- 저장된 로그는 UC-0104(사용 이력 및 사용량 조회)를 통해 개발자/관리자가 조회할 수 있다.
- 모든 표준API 및 표준MCP 호출 이력이 인증키 단위로 관리된다. (UC-0102/UC-0103 사후조건과 연결)

## 6. 미결/후속 검토 사항 (전면 재검토 필요)

- **로그 저장과 응답 반환의 순서/독립성**: UC-0102 기본 시나리오상 "스트림 종료 시 종료 신호를 반환하고, 호출 정보 및 사용량 이력을 기록한다"로 되어 있어 응답 반환 이후 비동기로 기록하는 것으로 보이나, 이 UC에서 명시적으로 동기/비동기 여부를 확정할 필요.
- **실시간성**: 호출 발생 시점과 UC-0104에서 조회 가능한 시점 사이의 지연(실시간/준실시간/배치 집계)이 정의되어 있지 않음. (UC-0104 미결사항과 동일 이슈.)
- **로그 보존기간(retention)**: UC-0104 예외 시나리오에 "보존기간이 지난 이력은 정책에 따라 제한"이라는 언급이 있으나, 실제 보존기간을 결정하고 관리(만료 로그 삭제/아카이빙)하는 주체가 이 UC인지 확정 필요.
- **로그 유실 방지**: Gateway 자체 장애 시 로그 유실을 방지하기 위한 방식(예: 큐잉, 별도 저장소 이중화 등)이 이 UC의 범위인지, 비기능요구사항(NFR)으로 별도 관리할지 확정 필요.
- **스트리밍 응답의 로그 단위**: UC-0102가 스트리밍으로 확정되었으므로, 청크 단위로 로그를 남기는지 최종 응답 완료 시 1건으로 집계하여 남기는지 확정 필요.
