# UC-0303. 인증키 신청을 관리한다

> ⚠️ 본 문서는 원본 PPTX(Slide 2)의 Use Case 목록에는 존재하나 상세 시나리오가 작성되지 않았던 항목입니다. UC-0101에서 "관리자 승인 필수"로 확정되었기 때문에, 이 UC는 사실상 UC-0101 기본 시나리오의 6~9단계(관리자 승인/발급)를 관리자 관점에서 상세화한 것입니다. 아래는 그 확정사항을 반영한 초안이며, 승인 화면의 세부 UI/절차는 별도 확정이 필요합니다.

## 1. Use Case 개요

| 항목 | 내용 |
|---|---|
| Use Case ID | UC-0303 |
| Use Case 명 | 인증키 신청을 관리한다 |
| 주요 Actor | 관리자 |
| 주요 시스템 | AI Gateway |
| 목적 | 관리자는 인증키 요청을 확인하여 승인한다 |
| Trigger | 개발자가 UC-0101을 통해 인증키를 신청한 경우 |
| 관련 SFR | SFR-010, SFR-005, SFR-009 |

## 2. 사전 조건

- 개발자가 UC-0101을 통해 인증키 신청을 제출한 상태여야 한다.
- 관리자는 인증키 신청 승인 권한을 보유하고 있어야 한다. **관리자는 특정 테넌트에 소속되지 않으며, 전체 테넌트의 신청 건을 관리한다(테넌트별 담당 관리자 구분 없음).**
- **(UC-0101 확정사항)** 신청 건은 신청 시점에 선택된 AI 자원 세트로 고정되어 있으며, 승인 이후 자원 추가는 불가하다(추가 필요 시 별도 신규 신청).

## 3. 기본 시나리오

| 단계 | Actor | 수행 내용 |
|---|---|---|
| 1 | 관리자 | AI Gateway 관리 화면에서 대기 중인 인증키 신청 목록을 조회한다. |
| 2 | 관리자 | 신청 건을 선택하여 신청자(개발자), 정보시스템, 요청 AI 자원(Model/RAG/MCP) 상세 내용을 확인한다. |
| 3 | 관리자 | 신청 내용이 테넌트별 AI 자원 사용 정책 및 권한 범위 내에 있는지 검토한다. |
| 4 | 관리자 | 신청을 승인 또는 반려한다. |
| 5 | AI Gateway | 승인된 경우, 최대 1년의 유효기간을 설정하여 인증키를 발급한다. *(UC-0101 확정사항 반영)* |
| 6 | AI Gateway | 반려된 경우, 반려 사유와 함께 개발자에게 통보한다. |
| 7 | 관리자 | 처리 결과(승인/반려) 이력을 확인할 수 있다. |

## 4. 예외/대안 시나리오 (초안)

- 신청 건이 이미 처리(승인/반려)된 상태에서 중복 처리 시도 → 처리 불가 안내
- 신청된 AI 자원 중 일부가 승인 시점에는 더 이상 제공되지 않는 경우 → **(미결)** 부분 승인이 가능한지, 전체 반려 후 재신청해야 하는지 확정 필요.

## 5. 사후 조건

- 승인된 신청 건에 대해 UC-0101의 인증키 발급 프로세스가 진행된다.
- 반려된 신청 건은 인증키가 발급되지 않으며, 개발자는 UC-0101을 통해 재신청해야 한다.
- 모든 신청 건의 처리 이력(승인자, 처리일시, 승인/반려 사유)이 관리자에 의해 조회 가능하다.

## 6. 미결/후속 검토 사항

- **승인 SLA(처리 기한)**: 신청 후 승인까지 목표 처리 시간이 정의되어 있지 않음. 개발자 입장에서 신청-발급 사이의 대기시간 예측이 어려움.
- **부분 승인 가능 여부**: 신청한 자원 세트 중 일부만 승인하고 일부는 반려하는 것이 가능한지, 혹은 전체 승인/전체 반려만 가능한지 확정 필요. (UC-0101에서 "신청 시점의 자원 세트로 고정"이라 정했으므로, 이 확정사항과 정합성 있게 결정 필요.)
